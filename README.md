# Blackcat.petsitter - Online Booking Management Web Application

## Abstract

This web application is a single-organization online booking and management platform for Blackcat.petsitter catered towards Hong Kong pet owners alongside SaaS foundations. It connects the pet owners with the organization personnel of Blackcat.petsitter, including the owner and staffs.

## Workflow Summary

The web application targets Pet Owners looking for door-to-door petcare services, the owner and the staffs of Blackcat.petsitter as the primary target audiences. In summary, pet owners apply for a booking, the owner confirms the booking and let the pet owners proceed with payment, and assign staffs to the respective booked services. After a completed door-to-door service, staffs can generate reports about completed tasks and to-do list for the next visit. The owner is able to adjust the booking status and view all transaction history, while the staffs are limited to only viewing their assigned bookings.
